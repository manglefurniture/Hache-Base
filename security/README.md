# Security

Patrones de seguridad reutilizables de Hache-Base.

## Objetivos

- autenticación centralizada;
- autorización por rol y contexto;
- protección de APIs;
- CSRF donde corresponda;
- rate limiting;
- manejo seguro de errores;
- secretos fuera del repositorio;
- trazabilidad de mutaciones administrativas.

Los ejemplos deben ser seguros por defecto y no incluir credenciales reales.
